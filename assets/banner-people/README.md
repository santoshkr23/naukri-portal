# Banner photos

Photos placed here appear on the right side of every post's banner, instead of the drawn student.

- **Best:** PNG with a transparent background (the person is cut out). A normal JPG/PNG photo is shown in a rounded frame instead.
- **Size:** about 1000 px tall is plenty.
- **Matching:** if the file name contains a word from the post title, that photo is used for the post —
  e.g. `police.png` for police jobs, `railway.png`, `teacher.png`, `bank.png`, `nurse.png`. Other posts use the
  remaining photos (each post always gets the same one).
- Use only photos you have the right to use (AI-generated by you, or free-licence stock). Never photos of real people
  taken from other websites.
